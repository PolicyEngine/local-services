uv is pinned to 0.13.6, written once as `pyproject.toml`'s `[tool.uv] required-version`: other uv releases refuse to run the project, and every workflow's `setup-uv` step reads the release from there. CI runs `uv lock --check`, and runs every command in the environment `uv.lock` locks (`uv run --locked`), except registered sites that cannot, such as the collector contract test against the built wheels and the installed-artifact check, which installs the wheels as a user would. A new workflow, `update-dependencies.yaml`, relocks `uv.lock` with upgrades every Monday and opens a pull request with the result from a new branch, closing the earlier relock pull requests nobody else pushed to. Registered rules check all three. The wheels are unchanged.
