`microcosm-emitter telemetry-token --lifetime-seconds N` exchanges this machine's Hugging Face credential for a telemetry-only collector token and prints it, its expiry and the collector origin as JSON, with its own exit code for each failure and no credential in any output. An emitter given such a token in `MICROCOSM_COLLECTOR_TOKEN`, `MICROCOSM_COLLECTOR_TOKEN_EXPIRES_AT` and `MICROCOSM_COLLECTOR_ORIGIN` uses it instead of a Hugging Face credential and sends it only to that collector; the origin variable is only checked, and an unusable value in any of the three stops the emitter at start, before it accepts any request from the build. From 30 seconds before that token expires, or after a 401, runs stay pending for a later emitter with a Hugging Face login instead of becoming local-only. `microcosm-emitter version` also prints the collector origin.
