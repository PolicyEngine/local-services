`microcosm-emitter telemetry-token --lifetime-seconds N` exchanges this machine's Hugging Face credential for a telemetry-only collector token and prints it, its expiry and the collector origin as JSON, with its own exit code for each failure. An emitter given such a token in `MICROCOSM_COLLECTOR_TOKEN`, `MICROCOSM_COLLECTOR_TOKEN_EXPIRES_AT` and `MICROCOSM_COLLECTOR_ORIGIN` uses it instead of a Hugging Face credential; the origin variable is only checked, and a different origin stops the telemetry module at start. When that token expires or is refused, runs stay pending for a later emitter with a Hugging Face login instead of becoming local-only. `microcosm-emitter version` also prints the collector origin.
