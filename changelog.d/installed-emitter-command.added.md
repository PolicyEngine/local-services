Add the `microcosm-emitter` command, so `uv tool install microcosm-emitter` installs the emitter outside the build's Python environment. A build starts `microcosm-emitter host` as its own child process, which inherits the build's environment and user. The host can read its parent's creation time itself, answers `hello` with the emitter version, accepted socket protocol versions and loaded modules, and can skip requested modules that it does not install.
