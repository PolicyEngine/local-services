`microcosm-emitter status --spool <path>` prints each run in a spool database, with its upload state, reason and undelivered event count, as JSON, reading the file without changing it. `microcosm-emitter deliver --spool <path>` delivers a spool's pending runs, such as a copy from a build on Modal, with this machine's Hugging Face login, without pruning undelivered events, and leaves the copy unchanged when the login is missing or refused.
