`microcosm-emitter status --spool <path>` prints each run in a spool database, with its upload state, reason and undelivered event count, as JSON, reading the file without changing it. `microcosm-emitter deliver --spool <path>` delivers a spool's pending runs, such as a copy from a build on Modal, with this machine's Hugging Face login, without pruning undelivered events or changing permissions. It leaves the copy unchanged when the login is missing or refused, stops with the remaining runs pending if the login fails partway, leaves a run that another Hugging Face user registered pending for that user (exit 8), and rolls back a write left unfinished in the copy's journal only once a recovered copy of the file passes its check. Both commands exit 9 for a file they cannot use, and 7, printing only the error's type, for an unexpected error.
