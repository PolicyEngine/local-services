- Send to the collector's production hostname by default (`PRODUCTION_COLLECTOR_URL`), instead of the Cloud Run address of the same production service. The hostname stays the same when the collector moves to another Google Cloud project. The Cloud Run address stays in `TRUSTED_COLLECTOR_ORIGINS` as `CLOUD_RUN_COLLECTOR_URL`, so a module's `collector_origin` setting can still select it if the hostname has to be rolled back. No environment variable selects the destination.
- Deliver collector submissions queued for any trusted origin through the origin the emitter resolves, since every trusted origin reaches the same production collector. Submissions that earlier releases queued for the Cloud Run address are submitted and checked through the hostname after an upgrade, and a bundle handed over again joins its queued submission instead of printing "A bundle could not be queued for the collector". Submissions queued for a development collector still go only to that collector.
